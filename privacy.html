MSFS Pilot Academy Privacy Policy

Effective date: 9 October 2026

Summary: MSFS Pilot Academy is a private, non-commercial local application. It uses YouTube API Services to search public aviation-training videos and obtain public metadata. It does not require Google/YouTube sign-in, does not access private YouTube account data, and does not download or store YouTube audiovisual content.

1. Use of YouTube API Services

MSFS Pilot Academy uses YouTube API Services for public video discovery and metadata retrieval. The current implementation uses an API key and does not use OAuth 2.0 user authorization.

2. Data accessed

The Academy may retrieve public, non-authorized YouTube API data including video title, video ID, channel title, publication date, thumbnail URLs, description, duration, public statistics such as view count when available, and whether captions are indicated as available. It may also store user-created research labels such as Saved, Reviewed, Ignored, comparison selections, notes and procedure-project links.

The Academy does not request, collect or store YouTube usernames, passwords, login credentials, private account data, private playlists, private watch history, or private channel data.

3. How the data is used

Public YouTube metadata is used only to help the user discover and organize aviation-training references relevant to Microsoft Flight Simulator aircraft, systems, navigation, procedures and simulator operations. YouTube sources may be compared with aircraft manuals and other authoritative references before being used in a training procedure.

YouTube videos remain hosted on YouTube. Playback, when used, is provided by the YouTube embedded player or a link to YouTube. The Academy does not download, import, back up, cache for offline playback, or re-host YouTube audiovisual content.

4. Storage, refresh and deletion

The Academy may temporarily cache public YouTube API search and metadata results locally to reduce unnecessary API requests. Non-authorized YouTube API data is refreshed or deleted no later than 30 calendar days after retrieval. Search cache entries may be refreshed much sooner.

User-authored notes, classifications and procedure work may be retained locally because they are created by the user rather than returned by the YouTube API. If those records include copied API metadata, the API metadata portion is refreshed or removed within the required period.

The Academy provides controls to clear the YouTube search cache and delete locally saved research records. Deleting Academy data does not delete data or content from YouTube.

5. Sharing and third parties

The project is private and non-commercial. YouTube API data is not sold, rented, used for advertising, or provided to data brokers. The Academy does not operate an advertising network and does not use YouTube data to profile users.

6. Cookies and device storage

The local Academy may use local browser storage and local files on the project owner's PC to remember research state, course progress and temporary API cache data. This storage is used only for the Academy's functionality. The public compliance website does not use advertising cookies.

7. Security

The YouTube API key is stored locally in the Academy configuration on the project owner's PC and is not intentionally exposed in the public website. Reasonable local security controls are used to protect the key and locally stored data.

8. User control and deletion

The user can clear cached YouTube search results and remove saved research items from within the Academy. Because the current API integration does not use OAuth 2.0 or Authorized Data, there is no Google authorization token to revoke. If OAuth is introduced in the future, the policy and application will be updated before that feature is used.

9. Google and YouTube policies

MSFS Pilot Academy uses YouTube API Services and is subject to the YouTube Terms of Service. Google's handling of information is described in the Google Privacy Policy. The project also follows the YouTube API Services Developer Policies.

10. Contact

This project is operated by an individual for private educational use. Contact information is supplied directly to Google in the YouTube API quota/compliance application.
