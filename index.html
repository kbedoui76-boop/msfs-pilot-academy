Flight-simulation learning, organized like a real academy.

MSFS Pilot Academy is a private local training application for Microsoft Flight Simulator. It combines aircraft manuals, aviation references, structured lessons, interactive cockpit study, training missions, and a research workflow for finding useful public aviation videos on YouTube.

PROJECT STATUS

Local Academy application

The full Academy runs locally on the project owner's PC. This public site exists to explain the project, its YouTube API use, privacy practices, and terms for compliance review.

How YouTube is used

What the Academy does

The project is designed to teach flight-simulation skills, aircraft systems and procedures while keeping the source trail visible.

Aircraft learning

Manual-backed aircraft courses, cockpit orientation, checklists, systems explanations and guided training flights.

Research workflow

Find relevant public aviation videos, save useful references, compare them with manuals and authoritative sources, then build verified training procedures.

Source library

Aircraft manuals and aviation references remain the primary technical source. YouTube videos are supporting research references, not the sole authority.

YouTube integration

The Academy uses YouTube API Services only for public discovery and metadata. It does not upload videos, modify YouTube accounts, or download/re-host YouTube audiovisual content.
