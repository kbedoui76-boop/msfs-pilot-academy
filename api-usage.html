YouTube API Services

How MSFS Pilot Academy uses YouTube

This page describes the exact current API use for compliance review.

Research workflow

Search

The user enters an aviation topic such as “A320 ILS landing.” The Academy sends a public YouTube search request.

Review

The Academy displays returned public metadata and links to the original video on YouTube.

Organize

The user may mark a result as saved, reviewed or ignored, and may attach their own notes.

Compare

Useful video references are compared with aircraft manuals and other authoritative sources before being promoted into a training procedure.

Transcript handling

The current public YouTube Data API integration does not automatically download arbitrary public-video transcripts. If transcript analysis is performed, transcript/caption text must be provided separately by the user from a lawful source. The Academy does not claim that metadata access is equivalent to watching or understanding the complete video.

Data retention

Public non-authorized API metadata is cached only as needed for application functionality and is refreshed or removed within 30 calendar days. User-created notes can remain longer because they are authored by the user rather than returned by the YouTube API.
